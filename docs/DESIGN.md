# Дизайн-система

RouteGuard использует спокойную контрастную палитру: глубокий navy для навигации, teal для подтверждённых действий, светлые поверхности и тёплые акценты только для риска. Красный обозначает просрочку/ошибку, но не заполняет большие области без необходимости.

Основные принципы:

- сначала действие и его причина, затем вторичные медицинские данные;
- статус не передаётся одним цветом — рядом всегда есть текст;
- кнопки записи и завершения явно разделены;
- помощник звонка расположен рядом с маршрутом, а не на отдельном потерянном экране;
- таблицы прокручиваются внутри карточки и не расширяют страницу;
- интерактивные элементы имеют keyboard focus, подписи и достаточную область нажатия;
- анимации отключаются через `prefers-reduced-motion`.

Контрольные ширины: 390 px (телефон), 768 px (планшет), 1440 px (desktop). На узких экранах навигация становится выдвижной, панели складываются в одну колонку, а реестры сохраняют внутренний горизонтальный скролл.
