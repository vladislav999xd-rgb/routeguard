# Дизайн-система

RouteGuard использует тему «Графит и шалфей»: тёмный графит для навигации, спокойный шалфей для подтверждённых действий, белые поверхности и тёплые акценты только для риска. Красный обозначает просрочку/ошибку, но не заполняет большие области без необходимости. Интерфейс набран локально подключённым вариативным шрифтом Golos Text и не зависит от внешнего CDN.

## Токены интерфейса

| Активный пункт меню | `#3D554A` |
| Основной акцент | `#32745D` |
| Акцент при наведении | `#285E4B` |

| Предупреждение / фон | `#946214` / `#FFF4DF` |

Основные принципы:

- сначала действие и его причина, затем вторичные медицинские данные;
- статус не передаётся одним цветом — рядом всегда есть текст;
- кнопки записи и завершения явно разделены;
- помощник звонка расположен рядом с маршрутом, а не на отдельном потерянном экране;
- на desktop карточка пациента занимает правую колонку, на средних экранах открывается поверх очереди, на телефоне — на весь экран;
- таблица на телефоне перестраивается в карточки и не создаёт горизонтальную прокрутку;
- интерактивные элементы имеют keyboard focus, подписи и достаточную область нажатия;
- анимации отключаются через `prefers-reduced-motion`.

Контрольные ширины: 390 px (телефон), 768 px (планшет), 1280 px (ноутбук) и 1440 px (desktop). На узких экранах навигация становится выдвижной, панели складываются в одну колонку, а реестры превращаются в вертикальные карточки.
