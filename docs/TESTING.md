# Тестирование

## Окружение

Автоматические проверки используют локальный режим `RG_DEV=1` и SQLite. Production-контур приложения рассчитан на MySQL, поэтому подключение к реальному серверу MySQL проверяется отдельно при развёртывании.

## Быстрый запуск тестов

```powershell
$env:RG_DEV='1'
php tests/smoke.php
php tests/call_assistant.php
```

## Статические проверки

```powershell
rg --files -g "*.php" | ForEach-Object { php -l $_ }
node --check assets/app.js
```

## Что покрывает smoke-тест

- создание ровно 20 пациентов в демосессии;
- изоляцию двух рабочих пространств;
- заполнение расписания на 30 дней;
- блокировку повторного бронирования слота;
- защиту от повторной отправки одного действия;
- завершение маршрута P006 после записи и выполнения;
- запрет закрытия P013 с незавершённым обязательным шагом;
- запрет закрытия P012 без требуемого подтверждения.

## Что покрывает тест помощника

- сценарий возврата после отмены для P006;
- сценарий повторной записи после неявки для P007;
- согласование альтернативы для P008;
- напоминание об активной записи для P003;
- наличие чек-листа вопросов;
- ограничение сценария только организационными вопросами.

## Проверенное вручную

- основные страницы отвечают HTTP 200 без PHP Warning, Deprecated и Fatal;
- результат звонка сохраняется в комментариях и истории;
- Chart.js загружается локально и строит диаграммы;
- обзор, очередь и карточка проверены на desktop;
- очередь проверена на ширинах 1024 и 390 px;
- `FIX/fix.php` применяет обновление, создаёт резервные копии и пропускает повторный запуск;
- ZIP-архивы используют пути, совместимые с Linux-хостингом.

## Что проверяется только на хостинге

- фактическое подключение к MySQL 5.7/8.0;
- обработка `.htaccess` конфигурацией Apache;
- выпуск и перенаправление на HTTPS;
- права файловой системы для установщика и обновлятора;
- хранение конфигурации выше `public_html`, если оно доступно.
