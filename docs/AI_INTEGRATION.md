# Подключение генеративной модели к МедМаршруту

## Решение для текущей версии

В MVP внешняя модель не подключена. Помощник координатора использует детерминированные шаблоны из `core/call_assistant.py`, поэтому работает без сети, оплаты и передачи медицинских данных третьей стороне. Этот механизм остаётся обязательным резервным режимом.

Если интеграция будет одобрена отдельно, Django уже имеет серверную границу `CoordinatorScriptProvider` в `core/ai_assistant.py`. Браузер не обращается к модели напрямую и не получает ключ API. Сейчас реализация провайдера и ключ отсутствуют: рабочий интерфейс всегда использует локальный шаблон.

```text
карточка пациента
  -> явное действие сотрудника
  -> подготовка минимального обезличенного контекста
  -> CoordinatorScriptProvider.generate_script()
  -> проверка схемы и ограничений
  -> черновик для сотрудника
  -> ручное подтверждение
  -> обычная доменная команда и аудит
```

Адаптер должен иметь ограниченную задачу: подготовить черновик организационного сценария разговора по уже утверждённым шагам. Он не ставит диагноз, не выбирает лечение, не назначает клинические сроки и не изменяет маршрут.

## Какие данные допустимы

По умолчанию модели не передаются ФИО, дата рождения, телефон, адрес, исходный документ или другие идентификаторы. Допустимый запрос состоит только из синтетического либо предварительно обезличенного набора:

- тип уже утверждённого организационного шага;
- его состояние и известная организационная причина контакта;
- разрешённые варианты действия, заданные системой;
- требуемый формат ответа и язык.

Передача даже обезличенных производственных данных требует отдельного согласования владельца, договорных гарантий провайдера и документированного основания обработки. Для демонстрации используются только синтетические данные.

## Обязательные проверки

1. Вход проходит allow-list полей, ограничение длины и удаление идентификаторов.
2. Ответ принимается только по строгой JSON-схеме: цель звонка, начало, вопросы и предложение.
3. Все поля ограничиваются по длине; HTML, ссылки и неизвестные ключи отклоняются.
4. Сервер повторно проверяет, что текст не содержит диагноза, назначения или нового срока медицинской помощи.
5. Результат помечается как черновик модели и не сохраняется как действие без проверки сотрудником.
6. Таймаут, ошибка провайдера или неверный формат переключают интерфейс на шаблонный помощник.
7. В аудит пишутся версия адаптера, факт генерации, результат проверки и сотрудник, подтвердивший черновик. Секреты и полный медицинский текст в аудит не попадают.

## Возможные провайдеры и стоимость

Оценка зафиксирована 19 ноября 2026 года по публичным тарифам провайдеров. Это ориентир для будущего решения, а не выбранный поставщик и не обещание цены. Перед подключением тариф, доступность в нужной юрисдикции, условия обработки данных и налоги проверяются повторно.

Для сравнения принят один короткий организационный черновик: 600 входных и 250 выходных токенов, без поиска, аудио, кэша и дополнительных инструментов. Повторы и ошибки в базовую таблицу не включены; для бюджета разумно прибавлять 20% резерва.

Стоимость одного запроса рассчитывается по тарифу выбранного провайдера на момент подключения:

```text
стоимость = входные_токены / 1_000_000 * цена_входа
          + выходные_токены / 1_000_000 * цена_выхода
```

| Вариант для оценки | Вход / выход за 1 млн токенов | 1 черновик | 100 | 500 | 1000 |
|---|---:|---:|---:|---:|---:|
| OpenAI GPT-6 Luna, standard | $0.05 / $0.25 | $0.0000925 | $0.00925 | $0.04625 | $0.0925 |
| Anthropic Claude Haiku 5.5, до 100K входа | $0.10 / $0.50 | $0.000185 | $0.0185 | $0.0925 | $0.185 |
| Google Gemini 3 Flash Preview, standard | $0.50 / $3.00 | $0.00105 | $0.105 | $0.525 | $1.05 |

Источники: [OpenAI API pricing](https://developers.openai.com/api/docs/pricing), [Anthropic Claude Haiku](https://www.anthropic.com/claude/haiku), [Gemini Developer API pricing](https://ai.google.dev/gemini-api/docs/pricing). Суммы указаны в USD без налогов и пересчёта валют.

Перед выбором нужно прогнать минимум 100 синтетических запросов, измерить фактические токены и долю отклонённых ответов. Итоговый месячный бюджет считается как `число черновиков × измеренная стоимость × 1.2`.

## Резервная работа без ИИ

- `core/call_assistant.py` формирует безопасный организационный сценарий локально;
- карточка, запись, результат звонка, задачи и история продолжают работать без внешнего сервиса;
- отсутствие ключа API является штатным режимом, а не ошибкой установки;
- подключение модели не требует ASGI, фонового worker-процесса или очереди и совместимо с текущим WSGI-развёртыванием SprintHost.

До отдельного решения владельца реализация ограничена адаптером, строгой проверкой схемы, безопасным откатом на шаблон и этим отчётом: платный сервис и передача данных не включены.
