# Демонстрационные сценарии

| Код | Начальное состояние | Что показать | Ожидаемый результат |
|---|---|---|---|
| P001 | Черновик | Подтвердить маршрут | Статус «В работе», запись в аудите |
| P002 | Активный, без записи | Выбрать будущий слот | Одна активная запись, слот занят |
| P003 | Будущая запись | Открыть карточку | Дата, площадка и специалист видны |
| P004 | Запись на демодату | Выполнить шаг | Запись и шаг завершены |
| P005 | Завершён | Повторить чтение/команду | `completed_at` не меняется |
| P006 | Отмена пациентом | Открыть помощник | Сценарий возврата и новый слот |
| P007 | Неявка | Открыть задачи | Есть задача координатору |
| P008 | Нет слота до срока | Изучить приоритет | Объяснена причина внимания |
| P009 | Просрочен | Открыть обзор | Наивысший приоритет |
| P010 | Неполное заключение | Проверить карточку | Нет клинической интерпретации |
| P011 | Нет ответственного | Назначить сотрудника | Причина внимания снята |
| P012 | Нет документа | Добавить подтверждение | Маршрут закрывается |
| P013 | Два шага | Записать второй | Первый остаётся завершённым |
| P014 | Требуется перенос | Выбрать другой слот | Явная новая запись |
| P015 | Активный маршрут | Создать дубль | Ответ 409 для любого study UID |
| P016 | Нужно согласование | «Перезвонить» с датой | Создаётся задача callback |
| P017 | Отмена клиникой | Перезаписать | История причины сохраняется |
| P018 | Альтернативная площадка | Зафиксировать звонок | Без выбранного слота записи нет |
| P019 | Два выполненных шага | Открыть историю | Документы и завершение сохранены |
| P020 | Срок завтра | Открыть обзор | Приоритет «Сегодня/Скоро» объяснён |

Условная дата меняется в настройках демо. Сброс удаляет только текущий гостевой workspace и создаёт новый набор исходных сценариев.
