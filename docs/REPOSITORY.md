## Точки входа

### `index.php`

Главная HTTP-точка входа для страниц. Отвечает за навигацию, серверный HTML и подключение данных из репозитория. Здесь находятся обзор, очередь, карточка маршрута, расписание, события, демосценарии и настройки.

### `api.php`

Обрабатывает POST-команды: вход, открытие демо, комментарии, назначение ответственного, подтверждение плана, бронирование, перенос, отмену, неявку, выполнение шага и результаты звонка. Перед изменением данных проверяет сессию, CSRF, роль и workspace.

### `install.php`

Одноразовый production-установщик. Проверяет окружение и подключение к MySQL, создаёт таблицы, владельца и шаблон демоданных, после чего блокирует повторную установку.

## Каталог `app/`

### `bootstrap.php`

Общая инициализация: константы, конфигурация, часовой пояс, сессия, подключение PDO, функции безопасности, форматирование статусов и пересчёт маршрута.

### `RouteRepository.php`

Слой запросов на чтение. Формирует данные для показателей, очереди, карточки, расписания, событий и графиков. Все запросы ограничиваются текущим workspace.

### `CallAssistant.php`

Детерминированный конструктор организационного сценария звонка. Не изменяет данные и не формирует медицинских рекомендаций.

### `DemoSeeder.php`

Создаёт синтетические площадки, услуги, специалистов, пациентов, маршруты, слоты и события. Используется установщиком, публичным деморежимом и тестами.

## Интерфейс

| Путь | Назначение |
|---|---|
| `assets/app.css` | Визуальная система и адаптивные стили |
| `assets/app.js` | Меню, формы, мастер создания, фильтры и копирование текста |
| `assets/vendor/` | Локальные Bootstrap и Chart.js |
| `assets/fonts/` | Локальные файлы Montserrat |
| `screenshots/` | Материалы для README и визуальной проверки |

## Данные и схема

| Файл | Назначение |
|---|---|
| `schema.sql` | Production-схема MySQL |
| `schema.sqlite.sql` | Локальная схема SQLite |
| `config.example.php` | Публичный шаблон без реквизитов и токенов |
| `config.php` | Персональная конфигурация; всегда исключена из Git |
| `storage/` | Локальная БД и логи; коммитится только `.gitkeep` |

## Обновления

`FIX/fix.php` — единая точка доставки файловых исправлений на хостинг. Веб-запуск защищён maintenance token, перед заменой создаются закрытые резервные копии, повторное применение одной версии безопасно пропускается.

## Тесты

| Файл | Что проверяет |
|---|---|
| `tests/smoke.php` | Изоляцию демосессий, слоты, идемпотентность и ключевые правила маршрутов |
| `tests/call_assistant.php` | Выбор сценариев звонка и организационные ограничения |
| `tests/config_check.php` | Структуру персональной конфигурации перед развёртыванием |

## Что не должно попадать в Git

- `config.php` и любые копии с реальными реквизитами;
- `.env`, токены, пароли, дампы базы;
- содержимое `storage/`, кроме `.gitkeep`;
- ZIP-архивы для хостинга;
- резервные копии `FIX/backups/`;
- профили браузера и временные файлы визуальных тестов.
