# Интерактивный 3D-лендинг

## Сюжет и реализация

Ознакомительная страница `/` состоит из семи семантических HTML-сцен: первый экран, проблема, единый маршрут, рабочее место координатора, помощник звонка, объяснимая аналитика и финальный CTA. Текст, таблицы и кнопки остаются DOM-элементами; Canvas используется только как декоративный пространственный слой.

На экранах от 800 px запускается один lazy-loaded Canvas React Three Fiber. Процедурная лента построена `TubeGeometry` по `CatmullRomCurve3`; станции, карточки и окружение не требуют внешних моделей или текстур. Нативный прогресс страницы определяет позицию перспективной камеры на отдельной кривой. Скролл остаётся обычным и полностью обратимым, а лёгкий параллакс курсора не перехватывает ввод.

## Fallback и доступность

- до 800 px WebGL по умолчанию не загружается;
- при `prefers-reduced-motion: reduce` Canvas отключён;
- при отсутствии WebGL остаётся вертикальная 2D/2.5D-схема и весь основной контент;
- у страницы один `h1`, последовательная иерархия заголовков, skip-link и заметные focus-стили;
- CTA создаёт демосессию только существующим `POST /api/demo/open/` с cookie-сессией и CSRF, затем открывает `/app`;
- примеры помечены как синтетические, помощник описан как организационный и не даёт клинических рекомендаций.

## Сборка и размещение

```bash
cd frontend
npm ci
npm run build
```

Vite записывает production-сборку в `backend_static/app/`. Для SprintHost после локальных проверок пересоберите приватный пакет командой `powershell -ExecutionPolicy Bypass -File scripts/build_release.ps1 -ReuseExistingEnvironment`. Получившийся однофайловый `FIX/fix.php` обновляет приложение с резервной копией; production автоматически не изменяется.

## Проверка

```bash
python manage.py check
python manage.py test
cd frontend
npm audit
npm run build
npx playwright test
```

Playwright проверяет безопасный переход в демо и рабочий кабинет, семь сцен, WebGL на 1440/1024 px, мобильный fallback на 390/375/320 px, reduced motion и отсутствие горизонтального overflow. Автоматически проверялся Microsoft Edge; Safari и реальные слабые мобильные устройства требуют отдельной ручной проверки.

Локальный Lighthouse 11 октября 2026 года (headless Microsoft Edge, стандартное мобильное замедление, Django development server) показал: Performance 92, Accessibility 100, Best Practices 100, SEO 100; FCP 2,6 с, LCP 2,9 с, TBT 30 мс, CLS 0. Эти цифры характеризуют конкретный локальный прогон, а не обещание для production. Основной JS уменьшен до 92 КБ gzip; аналитика и 3D загружаются отдельными lazy-chunk только при необходимости.
