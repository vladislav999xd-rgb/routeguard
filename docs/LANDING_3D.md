# Интерактивный 3D-лендинг

## Сюжет и реализация

Ознакомительная страница `/` состоит из семи семантических HTML-сцен: первый экран, проблема, единый маршрут, рабочее место координатора, помощник звонка, объяснимая аналитика и финальный CTA. Текст, таблицы и кнопки остаются DOM-элементами, а полноэкранный Canvas содержит связанную пространственную историю за ними.

На экранах от 800 px запускается один lazy-loaded Canvas React Three Fiber. GSAP ScrollTrigger с `scrub` переводит прокрутку в единый обратимый прогресс. По нему камера проходит отдельную пространственную кривую, меняет цель взгляда и FOV, карточки расходятся и собираются, активируются станции, выдвигаются 3D-панели кабинета, звонка и аналитики, а в финале дополнительные маршруты образуют общую структуру.

## 3D-ресурсы и материалы

- маршрут и светящиеся связи: процедурные `TubeGeometry` по `CatmullRomCurve3`;
- платформы и станции: цилиндрическая геометрия, объёмные кольца и активные световые ядра;
- стеклянные панели: `RoundedBoxGeometry` и `MeshPhysicalMaterial` с transmission, thickness, IOR, clearcoat и отражениями;
- отражающее освещение: процедурный `RoomEnvironment`, преобразованный через PMREM;
- интерфейсы кабинета, звонка и аналитики: отдельная 3D-геометрия, а не изображения рабочих экранов;
- движущийся маркер маршрута: emissive-сфера и локальный источник света;
- внешние GLB/GLTF, изображения пациентов и удалённые текстуры не используются.

GSAP и WebGL-модуль загружаются отдельными lazy-chunk после появления основного заголовка и CTA. Основной JS остаётся около 92 КБ gzip.

## Fallback и доступность

- до 800 px WebGL по умолчанию не загружается;
- при `prefers-reduced-motion: reduce` Canvas отключён;
- при отсутствии WebGL остаётся вертикальная 2D/2.5D-схема и весь основной контент;
- у страницы один `h1`, последовательная иерархия заголовков, skip-link и заметные focus-стили;
- CTA создаёт демосессию только существующим `POST /api/demo/open/` с cookie-сессией и CSRF, затем открывает `/app`;
- примеры помечены как синтетические, помощник описан как организационный и не даёт клинических рекомендаций.

## Сборка и размещение

```bash
cd frontend
npm ci
npm run build
```

Vite записывает production-сборку в `backend_static/app/`. Для SprintHost после локальных проверок пересоберите приватный пакет командой `powershell -ExecutionPolicy Bypass -File scripts/build_release.ps1 -ReuseExistingEnvironment`. Получившийся однофайловый `FIX/fix.php` обновляет приложение с резервной копией; production автоматически не изменяется.

## Проверка

```bash
python manage.py check
python manage.py test
cd frontend
npm audit
npm run build
npx playwright test
```

Playwright проверяет безопасный переход в демо и рабочий кабинет, семь сцен и обратную прокрутку, WebGL на 1440/1024 px, мобильный fallback на 390/375/320 px, reduced motion и отсутствие горизонтального overflow. Контрольные кадры записываются для первого экрана, маршрута, кабинета, помощника звонка и финала. Автоматически проверялся Microsoft Edge; Safari и реальные слабые мобильные устройства требуют отдельной ручной проверки.

Локальный Lighthouse 11 октября 2026 года (headless Microsoft Edge, стандартное мобильное замедление, Django development server) показал: Performance 92, Accessibility 100, Best Practices 100, SEO 100; FCP 2,6 с, LCP 2,8 с, TBT 10 мс, CLS 0. Эти цифры характеризуют конкретный локальный прогон, а не обещание для production.
